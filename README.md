# The Elects Empire 👑

> "... In Christ"

**The Elects Empire** is a comprehensive digital ecosystem designed for Bible study, spiritual growth, and fellowship. It serves as a central hub for believers to engage with the Word, connect with their community, and manage their spiritual journey across multiple platforms.

---

## ✨ Key Features

### 📖 Scripture & Study
- **Bible Reader**: A feature-rich interface for reading and meditating on the living Word.
- **Study Guides & Notebooks**: Tools for deep dives, personal reflections, and organized note-taking.
- **Reading Plans**: Structured paths for consistent spiritual growth.
- **Scripture Memory**: Interactive challenges to hide the Word in your heart.

### 🕊️ Prophetic & Spiritual Insights
- **Journey of Prophetic Words (JPW)**: A dedicated space for recording and reflecting on divine guidance.
- **Insights & Devotionals**: Access to deep findings and daily nourishment for the spirit.
- **Biblical Roadmap**: A visual guide to spiritual growth and understanding.

### 🤝 Community & Connection
- **Fellowship Forum**: Engage in deep discussions and share spiritual breakthroughs.
- **Prayer Wall**: A space for communal intercession and celebrating answers to prayer.
- **Study Groups**: Connect with like-minded believers in smaller, focused circles.
- **Member Directory**: Find and grow with disciples in the community.

### 🎨 Multimedia & Tools
- **Sermon & Music Archive**: Revisit sacred messages and melodies.
- **Elects AI**: An AI-powered assistant to help navigate the archives and deepen understanding.
- **Global Search**: Quickly find scripture, insights, or discussions.
- **Calendar**: Stay updated on community gatherings and events.

## 🛠️ Technology Stack

- **Frontend**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **State & Backend**: [Supabase](https://supabase.com/)
- **Animations**: [Motion](https://motion.dev/)
- **Text Editor**: [Tiptap](https://tiptap.dev/)
- **AI Integration**: [Groq SDK](https://groq.com/)
- **Mobile**: [Capacitor](https://capacitorjs.com/) (Android/iOS)
- **Desktop**: [Electron](https://www.electronjs.org/)

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (latest LTS recommended)
- [npm](https://www.npmjs.com/)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Faith-Jackson/the-elects-empire.git
   cd the-elects-empire
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables:
   Create a `.env` file based on `.env.example` and add your credentials:
   - Supabase URL/Key
   - API Keys (Groq, etc.)

### Development
Start the development server:
```bash
npm run dev
```

## 📱 Cross-Platform Deployment

### Desktop (using Electron)
```bash
# Run in development mode
npm run electron:dev

# Build for production
npm run electron:build
```

### Mobile (using Capacitor)
```bash
# Android
npm run android:open

# iOS
npm run ios:open
```
